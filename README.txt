
AIS PORT ROUTING SYSTEM V3

SETUP:
1. Place your parquet dataset in this folder.
2. Rename dataset to:
   ais_sample.parquet

INSTALL:
pip install -r requirements.txt

RUN:
python main.py

FEATURES:
- Port-to-Port Routing
- Optimized vs Baseline Route
- Multi-Ship Simulation
- Interactive Marine Maps
- AIS Traffic Heatmaps
- Fuel Comparison Graphs

CONFIGURATION:
Edit these in main.py:
- START_PORT
- END_PORT
- NUMBER_OF_SHIPS
- SHIP_TYPES
